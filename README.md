# Pixel Leap

An original retro platformer: run, jump and stomp through three worlds, right in your browser.

**Play:** https://ishanroy2020.github.io/pixel-leap/

Pixel Leap is an original game — the art, code, chiptune audio and level layouts were all
made for this project. Nothing is copied from any existing game or franchise.

## How to play

Reach the goal beacon at the end of each level, collecting gems and stomping grumbles on the
way. You start with three lives; your best score is kept on the device.

### Touch

- Left / right buttons in the bottom-left corner.
- JUMP button in the bottom-right corner.
- Pause and mute buttons in the top-right corner.

### Keyboard

- Move: arrow keys or `A` / `D`.
- Jump: `Space`, `W` or `Up`.
- Pause: `P` or `Esc`.
- Mute: `M`.

### iPhone / iPad

Add the game to your Home Screen (Share → *Add to Home Screen*) to launch it fullscreen with
no browser chrome. The iPhone silent switch also mutes the sound, so flip it off (and check the
in-game mute button) if you cannot hear the music.
